# NASA ADC 2025

This is the Lambert STEM in Space's submission to the NASA App Development Challenge. The goal for this project was to visualize the flight path of NASA's Artemis II spacecraft, launching in September 2025. 

## Getting started

Ensure you have the latest Unity LTS Version installed. We will be using it for the challenge. 

Unity Download: https://unity.com/download

Then, ensure you have Git installed on your machine and run the following commands within your project folder:

```
git clone https://gitlab.com/lambert-stem-in-space/lambert-adc-2025.git
cd nasa-adc-2025
```
